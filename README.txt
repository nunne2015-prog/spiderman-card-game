Spider-Man Card Game Online v1.3

Запуск:
1. Установить Node.js.
2. Открыть терминал в папке проекта.
3. npm install
4. npm start
5. Открыть http://localhost:3000

Новое в v1.3:
- крупный индикатор «ВАШ ХОД / ХОД СОПЕРНИКА»;
- блокировка карт и действий не в свой ход;
- 60-секундный визуальный таймер (не завершает ход автоматически);
- история действий партии;
- простые анимации карт;
- подтверждение выхода;
- статистика на экране окончания;
- реванш по согласию обоих игроков;
- в реванше первым ходит другой игрок;
- защита сервера от слишком частых повторных действий;
- очистка заброшенных комнат и сохранение переподключения.
